Business Command Center
An all-in-one organizer built for modern small businesses juggling multiple lanes.

I built this to solve the chaos of running everything at once:
• 🤖 AI Projects — track which tool you used (ChatGPT, Midjourney, Claude, Canva AI), prompts, and where the content goes • 📱 Social & Website — Instagram, TikTok, Facebook, Shopify, website updates, email campaigns — all with due dates and priority • 👕 Clothing Merch — drop planning, mockups, product descriptions, promo schedules, and launch checklists 
How it works:
Kanban board with Planned | In Progress | Launched/Done, filter by category, search by tool/platform, priority dots, and a Focus Today sidebar so you always know what to do next.

No backend, no login — just open and start dumping your plans. Built with React + Vite + Tailwind, ready to deploy to GitHub Pages for free.
